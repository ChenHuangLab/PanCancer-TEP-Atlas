# Platelet bulk diagnosis: MHC-I benchmark

This directory contains a standalone release of the benchmark section of `Platelet_bulk_diagnosis_AUC.R` and `101_machine_learning_main.R`, together with the nine prepared RDS inputs. The model implementations were adapted from `21_ML_COM_method_new_version.R`, with `9_ML_method.R` reviewed as an earlier version. The original four scripts are kept outside this repository and are not needed to run the release script.

The aim is to compare a fixed five-gene geometric-mean score with models fitted to the same five MHC-I gene expression values. `GSE183635` is the training cohort; every other supplied RDS is evaluated separately. The source labels the workflow “101”, but the selected code actually evaluates **21 fitted model configurations** across nine algorithm families, plus the geometric-mean score. No validation cohort is used for fitting or selecting a final model.

## Input layout

The nine RDS inputs generated by the data-preparation parts of `Platelet_bulk_diagnosis_AUC.R` are included in `data/` next to the script:

```text
platelet bulk diagnosis ML benchmark/
├── Platelet_bulk_diagnosis_ML_benchmark.R
├── README.md
└── data/
    ├── GSE183635_5_mhc_i_expression_for_training_df.rds
    ├── GSE126446_5_mhc_i_expression_for_training_df.rds
    └── ... seven more external-study files
```

Each RDS must contain one `data.frame` with numeric `HLA-A`, `HLA-B`, `HLA-C`, `HLA-E`, and `HLA-F` columns (periods or underscores in gene names are accepted), a `Disease` column, and preferably `Sample`. The five gene values should be nonnegative expression or count values. `Disease` is mapped to class 0 for names containing `Control`, `healthy`, or `nonMalignant`, and to class 1 otherwise. Exceptions from the source analysis are `GSE126446` (`Mature` = 0, `Immature` = 1) and `GSE232027` (`low` = 0, `high` = 1). Inspect these mappings against the input metadata before interpreting AUCs.

The included `GSE232027` RDS already has distinct `HLA-B` and `HLA-E` columns. The source script also contains a correction for an older version with two `HLA-E` columns. This script applies that correction only if `HLA-B` is absent and there are exactly two `HLA-E` columns, and emits a warning. **Confirm the gene identity in the source data** before relying on that cohort's result.

## Run

Install the required R packages: `pROC`, `glmnet`, `randomForest`, `e1071`, `xgboost`, `gbm`, `lightgbm`, `superpc`, `pls`, `ggplot2`, and `writexl`. Then run:

```sh
Rscript Platelet_bulk_diagnosis_ML_benchmark.R
```

The default paths are `./data` and `./results` relative to the **script file**, regardless of the shell's current directory. To use another local directory:

```sh
Rscript Platelet_bulk_diagnosis_ML_benchmark.R --data-dir /path/to/data --output-dir /path/to/results
```

The script writes `all_model_auc_results.csv`, `all_model_auc_results.xlsx`, and `AUC_Heatmap.pdf` to `results/`. Rows are ordered by mean AUC across the supplied external datasets. Every external dataset is retained in the table and plot. The geometric mean is recalculated from the five supplied genes per sample, using half of that sample's smallest positive value as a pseudocount; all-zero rows receive score 0. The source's hand-entered geometric-mean AUC values are not reused, so differences from the original figure are possible if its source matrices or labels differ from these RDS files.

For ROC analysis, class 1 is the case group and **higher scores mean more evidence for class 1** (`pROC` direction `<`). Random forest and SVM use class probabilities rather than hard class labels. Stepwise forward selection starts from the intercept-only model. These corrections make the comparison interpretable but can change AUCs relative to the exploratory source script.

The nine supplied RDS inputs are tracked in Git. Generated results in `results/` are ignored by Git.
