# PanCancer-TEP-Atlas
Analysis code accompanying the PanCancer-Platelet-Atlas study, including target-cell selection, atlas integration and computational pathology workflows.

## Available analysis code

- [Biological characterization of PAS-associated regions](biological%20characterization%20of%20PAS-associated%20regions/README.md)
- [Platelet bulk diagnosis ML benchmark](platelet%20bulk%20diagnosis%20ML%20benchmark/README.md)
- [Single-cell HSC, megakaryocyte and platelet integration](single-cell%20HSC%20MK%20platelet%20integration/README.md)

## Data availability

The processed clustered platelet Seurat object (`clustered_Platelet_with_pathway_score.rds`) has been deposited in Harvard Dataverse and submitted for review (reserved DOI: 10.7910/DVN/HVN3IO). The larger Harmony-integrated RDS object is not part of this deposit.
